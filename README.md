# There is no universal Fσ equivalence relation

This repository formalizes the main result of arXiv:2610.31052 that there
is no universal Fσ equivalence relation.

## Check locally

From the repository root, with the pinned Lean toolchain installed:

```sh
lake exe cache get
scripts/check.sh
scripts/check-comparator.sh
```
